# Atomic Environment Explorer

A web app for exploring atomic coordination environments (CN12 and others) in crystal structures from CIF files.
Developed in the Oliynyk Lab, Hunter College (CUNY).

## Run it on your computer

1. Install Python 3.12.
2. In this folder, run:

```
pip install -r requirements.txt
streamlit run 02_code/atomenv_app.py
```

3. Your browser opens at http://localhost:8501.

Demo CIF files are in `03_data/demo_cod`. More details: `docs/ATOMIC_ENVIRONMENT_EXPLORER.md`.
